# PKU-Replay-Saver

使用当前浏览器登录态保存北大录播，无需服务器、本地 FFmpeg、WASM 或 CDN。

## 安装

1. 安装 Tampermonkey。
2. 在 GitHub 打开 `PKU-Replay-Saver.user.js`，点击 **Raw** 安装；也可在 Tampermonkey 中导入文件。
3. 重新打开已登录的录播页面并开始播放。手动更新时替换已有脚本，避免重复安装。

支持 `https://course.pku.edu.cn/webapps/bb-streammedia-hqy-BBLEARN/` 下的录播页面和其中的嵌套播放器。面板位于滚动容器外的下方，显示进度、速度、剩余时间，支持取消、重试和重命名。Chrome / Edge 如无法运行脚本，可在扩展设置中启用允许用户脚本。

## 使用

在录播列表 `videoList.action` 中，底部的「下载设置：」提供加大的「仅视频（有声音）/ 仅音频 / 视频和音频」选择器及独立的音频格式选择器，默认 AAC (.m4a)，也可选 MP3 (.mp3)。选择统一用于各行和「下载全部」，排队任务记住点击时的设置。行内下载按钮使用与「观看」链接相同的颜色、无边框，悬停显示下划线；底部批量按钮保留蓝色样式。每个待处理行都有自己的排队圆环和取消按钮，轮到该行时显示实际进度。完成一行就恢复该行的保存和音频操作，无需等待整批结束；这些操作使用独立队列，最多同时执行一个，可与下一条视频下载并行。取消一行只停止该行，底部取消停止整批。速度和剩余时间在空间不足时折叠到悬停提示；控件提前预留固定位置，避免表格跳动。列表不显示缓存时长、5 分钟测试或播放地址工具，原观看链接保留。

下载设置包含独立的视频格式（MP4 / fMP4 / TS）与音频格式选择器，视频默认 MP4。选择「仅视频（有声音）」时音频格式置灰，选择「仅音频」时视频格式置灰，选择「视频和音频」时两者可用；切换内容不会清空已选格式，排队任务保留点击时的设置。「仅音频」固定使用 MP4 中间文件，不受已置灰的视频格式影响。少数直接提供 MP4 文件的旧录播需选择 MP4；再次保存已有视频保留其实际格式。

支持目录读写的 Chrome / Edge 会优先弹出系统目录选择框。本页选一次后，后续视频、音频和保存副本都直接写入同一目录，不逐文件询问；可以点「更改目录」重新选择，刷新页面后重新选择。同名文件自动加编号，保留已有文件。目录直写不维护额外的完整视频缓存，音频提取直接读取已保存的视频，已保存文件不会自动删除，播放器也隐藏缓存时长选项。Safari 等不支持目录选择接口的环境保留浏览器私有存储和下载管理器的兼容路径。

列表下载通过后台观看页获取当前登录态和播放信息，随后关闭后台播放器。HLS 封装为普通 MP4；已有 MP4 文件按最多 8 MiB 的字节范围读取。取消正在处理的行会等待未完成输出回收，再处理其他排队项；底部取消停止整批。下载失败会停止后续下载项，独立音频转换失败不会中断其他视频下载。离开或刷新页面会清空所有队列并停止当前任务。兼容路径的批量源文件保留到批次及读取结束，再开始缓存保留期；缓存过期时可选择已保存的视频继续操作。

「仅视频（有声音）」保存可正常播放的原始录播文件，不另存音频；「视频和音频」共用一次下载，再从已保存的视频提取音频。「仅音频」只交付音频文件；现有转换器需要临时源文件，目录直写模式下会在提取结束、所有读取释放后立即清理，不保留整段视频缓存，之后另存视频需重新下载。兼容路径仍按所选缓存策略保留源文件。AAC 默认保存为 .m4a，无需重新编码；MP3 兼容性更好，需要重新编码。已保存的内容显示「再次保存」，缓存或目标文件可用时直接复用。

兼容路径下，播放器会提示缓存保留时间，默认 5 分钟，可选 10、30、60 分钟、12 小时、24 小时或永不删除；列表保持默认 5 分钟，不显示此选项。读取和等待音频转换的源文件都有保护，直到提取结束才允许清理。更改时长会应用到当前视频和音频的浏览器缓存。「永不删除」的完整缓存保留在浏览器站点存储中，需自行管理；取消或失败的未完成文件仍立即回收。缓存过期不影响已保存的文件。

各界面使用同一套速度和剩余时间估算：忽略最初的快速分片，收集至少 4 秒和多个时间样本后才显示数值，期间显示「—」。最近样本取中位数后按时间平滑，持续变慢仍会调整预计时间；长时间没有进展时隐藏旧估算，恢复后重新采样。

先点「下载前 5 分钟测试」，再下载完整录播。测试按完整分片截取，可能略长于 5 分钟。下载和转换过程中请保持页面打开。

| 格式 | 说明 |
| --- | --- |
| MP4（默认） | 普通 MP4，重新生成完整样本索引，适合 Safari / QuickTime 等播放器。 |
| fMP4 | 分片 MP4；个人测试可能无法在 QuickTime Player 正常播放。 |
| TS | 解密后的原始 TS，适合 IINA / VLC。 |

三种视频格式保留原始音视频编码，实际容器与扩展名一致。也可在视频下载完成后单独点「保存音频」：AAC（默认）保存为 `.m4a`，无需重新编码；MP3 兼容性更好，需要重新编码。音频导出读取已下载的视频，不重复联网；支持单声道 / 双声道 AAC-LC、处理进度和取消。

媒体按分片和音频批次处理，不将整段录播或解码音频累计在内存中；完整 MP4 索引仍随时长增长。写盘时会为必要的数组切片创建独立缓冲区，避免 Safari 写入错误范围，额外内存限于当前写入。

TS 下载使用逐片本地封装路径，不启动视频转封装 Worker，也不将一个 TS 分片拆成多次调度。进度显示最多每秒刷新 10 次，阶段完成立即显示，速度估算继续接收全部采样；列表不再因自身界面更新反复扫描整张表。

下载时请保持页面打开。优先使用已授权目录直接保存，所选目录只在本页记住。兼容路径在完成后交给浏览器下载管理器；如果浏览器询问是否允许多个文件下载，请允许。完整临时副本按所选时长保留，读取期间不会删除；副本已清理时，可选择已保存的视频继续提取音频。

取消或失败会停止任务并回收未完成的临时文件，已完成的视频会保留。删除失败会保留清理记录并重试；浏览器被强杀后，下次页面运行且存储可用时恢复清理。通过保存对话框选择的目标由浏览器管理，脚本撤销未完成写入，不删除用户已有文件；撤销失败时需检查所选位置。

普通 MP4 在结束时生成索引，中断文件不会作为成品保存。目前不支持断点续传、直播、DRM、音视频分离或时间线不连续的录播。播放地址未检测到时，可在「播放地址设置」中填入 `.m3u8` 地址。
